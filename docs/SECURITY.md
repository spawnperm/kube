# Политика безопасности платформы Космос-Просто (Cosmoport)

**Версия:** 1.0.0  
**Статус:** Канонический стандарт безопасности проекта

---

## 1. Отчетность об уязвимостях (Reporting Vulnerabilities)

Безопасность участников чемпионата и целостность судейских протоколов — наш высший приоритет.

- Если вы обнаружили уязвимость безопасности, направьте отчет на: `security@cosmoport.pstu.tech` или `elf2com@gmail.com`.
- Пожалуйста, не публикуйте информацию об уязвимости публично до выпуска официального патча.

## 2. Модель угроз и меры защиты

### 2.1. Защита судейских протоколов и баллов

- Все доменные алгоритмы расчета (`scoring.ts`) выполняются в строго детерминированном виде с валидацией инвариантов (границы баллов, тай-брейки).
- На клиенте реализована защита от инъекций разметки (XSS) и санитизация текстовых полей решений и чата.

### 2.2. Заголовки безопасности веб-сервера (Nginx)

В конфигурации `nginx.conf` настроены жесткие заголовки:

- `Content-Security-Policy`: ограничение источников скриптов и фреймов.
- `X-Frame-Options: DENY`: предотвращение Clickjacking-атак.
- `X-Content-Type-Options: nosniff`: блокировка MIME-type sniffing.
- `Referrer-Policy: strict-origin-when-cross-origin`.
- `Permissions-Policy`: отключение доступа к камере, геолокации и микрофону, если они не требуются.

### 2.3. Безопасность цепочки поставок (Supply Chain Security)

- Зависимости проверяются через `npm audit` в каждом запуске CI.
- В GitHub Actions используется статический анализатор уязвимостей GitHub CodeQL SAST (`.github/workflows/security-scan.yml`).
- Action-шаги зафиксированы по версиям.
- Lock-файлы строго контролируются, отсутствуют непроверенные бинарные аддоны.
