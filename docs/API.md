# Спецификация API платформы КОСМОПОРТ (Cosmoport & CubeSat)

**Версия:** 2.0.0 (Unified Release)  
**Базовый URL:** `http://localhost:3000`  
**OpenAPI Спецификация:** [`docs/openapi.yaml`](./openapi.yaml)

---

## 1. Общие принципы

- **Формат данных:** JSON (`Content-Type: application/json; charset=utf-8`).
- **Сквозная трассировка:** Заголовок `X-Request-ID` (UUIDv4) передается в каждом запросе для корреляции логов в Pino.
- **Отказоустойчивость AI:** При временной недоступности Gemini API (коды 503, 429 или исчерпание квот) сервер автоматически переключается на встроенный физический движок `fallbackFor` без прерывания сессии пользователя.
- **Ограничение частоты запросов (Rate Limiting):**
  - Эндпоинты искусственного интеллекта (`/api/assistant/*`): до 30 запросов в минуту на IP.
  - Синхронизация комнат (`/api/sync/*`): до 60 запросов в минуту на IP.

## 2. Эндпоинты мониторинга и здоровья

### `GET /api/health`

Проверка работоспособности шлюза, статуса сервиса Gemini, аптайма и количества активных комнат.

**Пример ответа (200 OK):**

```json
{
  "status": "ok",
  "uptimeSec": 420,
  "timestamp": "2026-10-07T18:50:00.000Z",
  "activeRooms": 4,
  "geminiEnabled": true,
  "nodeEnv": "development"
}
```

## 3. Эндпоинты AI-Штурмана «Кубик» (Google Gemini)

### `POST /api/assistant/chat`

Отправка текстового запроса AI-штурману «Кубик» с учетом контекста командной миссии и выбранного профиля агента.

**Тело запроса:**

```json
{
  "message": "Какова дальность радиовидимости при угле места антенны 10 градусов на высоте 525 км?",
  "roleAgent": "professor",
  "teamContext": {
    "taskTitle": "Расчёт радиолинии UHF",
    "projectName": "Парма-3U",
    "step": "Этап 2"
  }
}
```

**Параметры:**

- `message` (_string, обязательный_): Вопрос участника или наставника.
- `roleAgent` (_string, опциональный_): Роль AI агента:
  - `"professor"` — Профессор прикладной физики и баллистики (по умолчанию).
  - `"engineer"` — Главный конструктор бортовых систем CubeSat.
  - `"cosmonaut"` — Бортинженер-испытатель и специалист по полезной нагрузке.
  - `"jury"` — Эксперт судейской коллегии по регламенту и критериям.
- `teamContext` (_object, опциональный_): Текущий проект команды для точного формирования контекста ответа.

**Пример ответа (200 OK):**

```json
{
  "reply": "Дальность радиовидимости D рассчитывается из сферической геометрии треугольника Земля-Спутник-Станция: при высоте H = 525 км и угле места ε = 10° максимальная наклонная дальность составляет приблизительно 1420 км, а радиус зоны обслуживания на поверхности Земли около 1150 км.",
  "roleAgent": "professor",
  "source": "gemini-ai"
}
```

### `POST /api/assistant/quiz`

Автоматическая генерация интерактивного физического квиза по выбранной теме или статье LLM-Wiki.

**Тело запроса:**

```json
{
  "topic": "Законы Кеплера и орбитальное движение",
  "grade": "10-11 класс",
  "count": 5
}
```

**Пример ответа (200 OK):**

```json
{
  "quiz": [
    {
      "id": "q1",
      "question": "Как изменится период обращения спутника, если радиус круговой орбиты увеличится в 4 раза?",
      "options": [
        "Увеличится в 2 раза",
        "Увеличится в 4 раза",
        "Увеличится в 8 раз",
        "Не изменится"
      ],
      "correctIndex": 2,
      "explanation": "Согласно 3-му закону Кеплера T² ~ a³, следовательно T ~ a^(3/2). При увеличении a в 4 раза период увеличится в 4^(3/2) = 8 раз."
    }
  ],
  "source": "gemini-ai"
}
```

## 4. Эндпоинты синхронизации между устройствами

### `POST /api/sync/push`

Сохранение локального состояния команды на сервере по 6-значному коду комнаты.

**Тело запроса:**

```json
{
  "roomCode": "ORION7",
  "state": {
    "team": {
      "id": "team-orion-3",
      "name": "Орион-3",
      "score": 85.5
    },
    "user": {
      "id": "u-cap",
      "name": "Алексей Смирнов",
      "role": "mentor"
    }
  }
}
```

**Пример ответа (200 OK):**

```json
{
  "success": true,
  "roomCode": "ORION7",
  "updatedAt": 1791393600000
}
```

---

### `GET /api/sync/pull/:code`

Получение актуального состояния проекта по коду комнаты при подключении с другого устройства (планшет, мобильный, проектор защиты).

**Пример ответа (200 OK):**

```json
{
  "success": true,
  "state": {
    "team": { "id": "team-orion-3", "name": "Орион-3", "score": 85.5 },
    "user": { "id": "u-cap", "name": "Алексей Смирнов", "role": "mentor" }
  },
  "updatedAt": 1791393600000
}
```

## 6. WebSocket Live Audio & Events

### `ws://localhost:3000/live`

Двунаправленный сокет для передачи звукового потока и трансляции телеметрических алертов в реальном времени.

**Формат сообщений клиента:**

```json
{
  "type": "audio_chunk",
  "format": "pcm16",
  "sampleRate": 24000,
  "data": "<base64_audio_payload>"
}
```

**Формат ответов сервера:**

```json
{
  "type": "assistant_voice_chunk",
  "data": "<base64_audio_payload>",
  "transcript": "Штурман Кубик на связи. Параметры орбиты стабильны."
}
```
