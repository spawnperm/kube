# Стратегия тестирования платформы Космос-Просто (Cosmoport)

**Версия:** 1.0.0  
**Тестовый раннер:** Vitest 3.x (V8 Coverage Provider) + Playwright (E2E)

---

## 1. Пирамида тестирования

```
           / \
          /   \     E2E тесты (Playwright): сценарии сдачи решений,
         / E2E \    переключение вкладок, модальные окна, PDF экспорт.
        /-------\
       /         \   Интеграционные тесты компонентов (Testing Library):
      / Component \  рендер вкладок, графиков Recharts, SVG орбитальных карт.
     /-------------\
    /     Unit      \  Модульные тесты (Vitest): математика ранжирования,
   /                 \ тай-брейки, физическая симуляция телеметрии, валидация.
  ---------------------
```

---

## 2. Уровни тестов и команды запуска

### 2.1. Модульное и компонентное тестирование (Vitest)

```bash
npm run test:run        # однократный прогон всех тестов
npm run test:coverage   # прогон с генерацией покрытия кода (lcov + text)
npm run test            # интерактивный watch-режим для TDD
```

- **Целевое покрытие доменной логики (`src/domain/**`):** ≥ 90%
- **Изоляция:** Все юнит-тесты выполняются без моков браузерного DOM в чистой среде, за исключением компонентных тестов, использующих `jsdom` и `@testing-library/react`.

### 2.2. Сквозное тестирование (Playwright E2E)

```bash
npm run test:e2e:install  # установка headless chromium браузера
npm run test:e2e          # запуск сквозных E2E сценариев
```

### 2.3. Статический анализ качества (Quality Gate)

```bash
npm run typecheck       # строгая проверка типов TypeScript (tsc --noEmit)
npm run lint            # линтинг ESLint 9 (jsx-a11y, react-hooks)
npm run format:check    # проверка форматирования Prettier
```
