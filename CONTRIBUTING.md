# Contributing

Спасибо за интерес к проекту «Космос-просто»!

## Как участвовать

1. Форкните репозиторий и создайте ветку от `main`:
   `feat/...`, `fix/...`, `chore/...`, `docs/...`.
2. Вносите изменения небольшими осмысленными коммитами.
3. Перед PR убедитесь, что проходят проверки:

```bash
npm ci
npm run typecheck
npm run lint
npm run format:check
npm run test:run
npm run build
npm run test:e2e   # требуется: npx playwright install chromium
```

4. Откройте Pull Request по шаблону. CI должен быть зелёным.

## Требования к коду

- TypeScript `strict`; избегайте `any`, используйте доменные типы из `src/types`.
- Нет комментариев в коде, кроме действительно неочевидных участков.
- Бизнес-логика — в `src/domain` / `src/services` чистыми функциями, UI — в компонентах.
- Для новых фич и багфиксов добавляйте тесты (Vitest).
- Для UI-изменений проверяйте доступность: клавиатура, видимый фокус, `aria`-атрибуты,
  поддержка `prefers-reduced-motion`.

## Безопасность

- **Никогда** не коммитьте секреты (`.env`, токены, ключи). Приватные ключи не должны
  попадать в клиентский бандл (никаких `VITE_*` с секретами).
- Сообщения об уязвимостях — приватно мейнтейнерам, не через публичные issue.

## Приоритетные направления

- Реальная аутентификация и серверный RBAC (сейчас роли переключаются на клиенте).
- Серверный API телеметрии (REST + WebSocket) с OpenAPI-контрактом.
- Плоджинг данных (сейчас всё в памяти, теряется при перезагрузке).
- Расширение покрытия тестами и e2e (Playwright).
