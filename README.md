# КОСМОПОРТ — Единая платформа кейс-чемпионата по физике и проектирования CubeSat

Единая цифровая космическая платформа, объединяющая школьный кейс-чемпионат по прикладной физике **«Космос-просто»** и инженерную среду проектирования наноспутников **CubeSat 3U**.

Платформа сочетает интерактивное 3D-моделирование космических аппаратов, полнофункциональный симулятор орбитальной телеметрии и радиомаяка AX.25, интеллектуального AI-оркестратора «Кубик» на базе Google Gemini, банк из 500 реальных прикладных задач, интеграцию с федеральной программой «Space-Pi» и радиосетью «СОНИКС», а также экспертную панель судейства и систему аналитики с расчётом индекса освоенного объёма (SPI).

## 🚀 Ключевые возможности

- **Единое пространство миссии:** переключение между 22 экранами и специализированными вкладками для участников, наставников, экспертов жюри и организаторов ЦУП.
- **Интерактивная 3D-модель спутника (Three.js):** фотореалистичный 3U CubeSat с визуализацией плат бортового компьютера (OBC), системы энергоснабжения (EPS), магнитных катушек ориентации (ADCS), антенного блока и полезной нагрузки; анимация раскрытия солнечных батарей и орбитального вращения.
- **Полноценный симулятор орбитальной телеметрии:** расчет параметров круговой НОО-орбиты (525 км, скорость 7.61 км/с), расчет энергетического баланса батарей, температуры процессора, параметров магнитного поля, AX.25 радиомаяка (437.425 МГц) с симуляцией 4 типов аномалий (вспышка на Солнце, падение напряжения, потеря связи, деротация).
- **AI-Агент «Кубик» (Google Gemini API):** серверный штурман-консультант (`gemini-3.8-flash`) с голосовым вводом/выводом (Web Speech API + WebSocket audio streaming), контекстом командной задачи и локальной базой знаний для оффлайн-режима.
- **Банк из 500 практических космических задач:** база данных задач по гравитации, баллистике, терморегулированию, оптическим полезным нагрузкам и радиолиниям с фильтрацией по лигам и орбитам.
- **Конструктор 3-слайдовой презентации:** встроенный редактор слайдов для очной защиты проектов перед жюри с режимом полноэкранной презентации.
- **Интеграция Space-Pi & СОНИКС:** паспорт миссии, идеи экспериментов для наноспутников, сеть приёмных станций СОНИКС и экспорт официальной заявки на запуск.
- **Аналитика расписания и график Ганта:** интерактивная таблица контроля этапов с метриками SPI (Schedule Performance Index), диаграммы распределения баллов на Recharts и экспорт в CSV.
- **Официальные наградные сертификаты:** векторная генерация дипломов победителей и сертификатов участников на клиенте с помощью `jsPDF`.
- **Мультиплатформенная синхронизация:** синхронизация прогресса по короткому коду комнаты и спаривание мобильных устройств экипажа по QR-коду для приёма телеметрии.

## 🛠️ Быстрый старт и установка

### Требования

- Node.js 20+ или Bun
- npm 10+

### 1. Клонирование репозитория

```bash
git clone https://github.com/spawnperm/cosmoport.git
cd cosmoport
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

Задайте ключ `GEMINI_API_KEY` (если ключ не указан, сервер автоматически использует встроенную базу знаний по физике).

### 4. Запуск в режиме разработки

```bash
npm run dev
```

Сервер запустится на **http://localhost:3000** (Full-stack режим: Express API + Vite Frontend в едином процессе).

### 5. Сборка для продакшена

```bash
npm run build
npm start
```

## 📦 Модули платформы

### 1. 3D-пульт управления и CAD-компоновка CubeSat 3U

- **3D-модель:** Полноценный Three.js рендеринг спутника с реалистичными материалами (анодированный алюминий, фотоэлектрические элементы солнечных панелей, медные катушки магниторок).
- **Инспектор подсистем:** Интерактивное выделение и зуммирование отдельных модулей:
  - Бортовой компьютер (OBC): процессор STM32/ARM, Flash-память, шина CAN/I2C.
  - Система энергопитания (EPS): MPPT-контроллеры, литий-ионные ячейки 18650, защита от перегрузок.
  - Система ориентации (ADCS): трехосевой магнетометр, гироскопы, электромагнитные катушки (магниторокеры).
  - Радиолиния: UHF/VHF трансивер, развертываемые штыревые антенны.
  - Полезная нагрузка (Payload): многоспектральная камера ДЗЗ или спектрометр гамма-излучения.
- **Взрыв-схема 3D CAD Blueprint:** Модальное окно с послойным разбором конструкции наноспутника.

### 2. Симулятор орбитальной телеметрии и маяка AX.25

- Непрерывная трансляция ключевых телеметрических параметров:
  - Высота орбиты: $H \approx 524.8$ км
  - Орбитальная скорость: $V \approx 7.61$ км/с
  - Напряжение шины питания и процент заряда АКБ
  - Температурный профиль бортового оборудования и аккумуляторов
  - Значения векторов магнитного поля Земли ($B_x, B_y, B_z$)
- Формирование пакетов любительского радиомаяка формата AX.25 на частоте 437.425 МГц.
- Управление симулятором: ускорение времени (1x, 2x, 5x, 10x), пауза и имитация внештатных ситуаций (Solar Flare, Battery Drop, RF Loss, Detumble Anomaly).

### 3. Регламент кейс-чемпионата и банк 500 кейсов

- **Этап 1: Физико-математическая модель:** расчет баллистики орбиты, периода обращения, затенения Землей, энергобаланса и теплового режима.
- **Этап 2: 3D/CAD компоновка и бортовые системы:** расчет массово-габаритных характеристик, компоновка плат формата PC/104, расчет радиолинии (Link Budget).
- **Этап 3: Защита миссии и презентация:** оформление 3 ключевых слайдов (Концепция, Инженерный расчет, Результаты) и защита перед комиссией.
- **Банк 500 кейсов:** каталог прикладных задач с фильтрацией по категориям (Физика космоса, Дистанционное зондирование, Астрофизика, Связь и IoT).

### 4. AI-Штурман «Кубик» и база знаний LLM-Wiki

- Интерактивный виртуальный помощник экипажа, обученный физике космического полета и стандартам CubeSat.
- Голосовой диалог на русском языке с мгновенной генерацией ответов.
- **LLM-Wiki:** структурированные статьи с математическими формулами (законы Кеплера, формула Циолковского, уравнение радиосвязи Фрииса, закон Стефана-Больцмана).
- **Орбитальный квиз-экзамен:** динамическое тестирование знаний физики космоса с наградами в виде опыта (XP), кристаллов энергии и топлива.

### 5. Программа Space-Pi и сеть станций СОНИКС

- Информационный раздел всероссийского проекта Space-Pi Фонда содействия инновациям.
- Каталог запущенных российских школьных и университетских кубсатов.
- Карта станций открытой сети приёма телеметрии «СОНИКС» с расчётом зон радиовидимости и ближайших сеансов связи.
- Интерактивный мастер подачи заявки на запуск спутника с формированием официального PDF-паспорта.

### 6. Панель жюри, инспекторы и аналитика SPI

- Карточки экспертной оценки команд по 5 критериям: физическая точность, инженерная реализуемость, научная новизна, оформление документации, качество защиты.
- Таймер защиты миссии (3:00 регламент) с предупреждающими звуковыми гонгами.
- **Аналитическая таблица бенчмарка этапов:** расчет метрик освоенного объема:
  - Planned Value (PV), Earned Value (EV), Actual Cost (AC)
  - Индекс выполнения расписания: $SPI = EV / PV$
  - Отклонение по срокам: $SV = EV - PV$
  - Интерактивная подсветка критических задержек и экспорт таблицы в CSV.

### 7. ЦУП Оргкомитета, CRM команд и администрирование

- Реестр 16 команд чемпионата с картотекой проектов и статусами прохождения этапов.
- Лента публикации новостей чемпионата и оперативная рассылка экстренных оповещений.
- Ролевая модель доступа (RBAC): Капитан, Физик-баллистик, Инженер, Программист, Жюри, Эксперт, ЦУП, Гость.
- Режим имперсонации (вход координатора под профилем любого участника).

### 8. Сертификаты (jsPDF), отчёты и командный чат

- Мгновенная генерация именных PDF-сертификатов участников и призеров со стилизованным космическим гербом, защитным QR-кодом и подписями оргкомитета.
- Выгрузка сводного PDF-отчета миссии.
- Командный чат с тематическими каналами (`#general`, `#technical`, `#orbit`), закреплением сообщений и реакциями.

## 🔌 API Контракты и справочник эндпоинтов

Подробная спецификация OpenAPI доступна в файле [docs/openapi.yaml](./docs/openapi.yaml) и [docs/API.md](./docs/API.md).

### 1. `GET /api/health`

Проверка работоспособности системы, аптайма и статуса Gemini.

```json
{
  "status": "ok",
  "uptimeSec": 128,
  "timestamp": "2026-10-07T18:50:00.000Z",
  "activeRooms": 3,
  "geminiEnabled": true,
  "nodeEnv": "development"
}
```

### 2. `POST /api/assistant/chat`

Диалог с AI-штурманом Кубиком.

```bash
curl -X POST http://localhost:3000/api/assistant/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Как рассчитать период обращения спутника на орбите 525 км?",
    "roleAgent": "professor",
    "teamContext": {
      "taskTitle": "Баллистика наноспутника",
      "projectName": "Восток-1",
      "step": "Этап 1"
    }
  }'
```

**Ответ:**

```json
{
  "reply": "Период обращения T рассчитывается по 3-му закону Кеплера: T = 2π * sqrt(a³ / μ), где большая полуось a = R_Земли + H = 6371 + 525 = 6896 км. Подставляя гравитационный параметр μ = 398600 км³/с², получаем T ≈ 95.1 минут.",
  "roleAgent": "professor",
  "source": "gemini-ai"
}
```

### 3. `POST /api/assistant/quiz`

Автогенерация физического квиза по материалам энциклопедии.

```json
{
  "topic": "Орбитальная механика",
  "grade": "10-11 класс",
  "count": 5
}
```

### 4. `POST /api/sync/push` и `GET /api/sync/pull/:code`

Синхронизация состояния проекта между устройствами команды по 6-значному коду.

### 5. `GET /api/crm/teams`

Получение реестра команд чемпионата с фильтрацией по статусам.

## 📖 Примеры использования

### Пример 1. Расчёт параметров радиолинии в консоли браузера

```typescript
import { calculateLinkBudget } from '@/src/domain/scoring';

const linkMargin = calculateLinkBudget({
  txPowerWatts: 1.0, // 30 dBm
  freqMhz: 437.425, // UHF радиомаяк
  distanceKm: 1200, // Дистанция при угле места 10°
  rxAntennaGainDbi: 12.0, // Наземная станция Яги
  txAntennaGainDbi: 2.15, // Бортовая четвертьволновая антенна
});

console.log(`Энергетический запас радиолинии: ${linkMargin.marginDb.toFixed(1)} дБ`);
```
